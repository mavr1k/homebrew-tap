# mavr1k/homebrew-tap

Homebrew tap for my apps.

```sh
brew install --cask mavr1k/tap/langcycle
```

| Cask | What it is |
|---|---|
| `langcycle` | [LangCycle](https://github.com/mavr1k/LangCycle): switches keyboard layouts in a fixed order, with a large on-screen indicator |

The apps are ad-hoc signed, not notarized. The casks clear the download quarantine flag after installing, so macOS shows no warning.
